# Wisejet Cranes website

Plain static site (HTML, CSS, JavaScript). No build step, no setup.

To publish on GitHub Pages: upload everything in this folder to the root of your repository,
then go to Settings > Pages and choose "Deploy from a branch" > main > / (root).

Note: most photos currently load from the old site (wisejetcranes.co.zw). When new photos are ready,
send them over and they'll be added to the site files.
